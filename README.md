#  Rotten Tomatoes Movie Rating Data Analysis
Data was manually obtained (copied from Rotten Tomatoes and pasted into Excel), cleaned with Excel VBA, and processed in Python.   

Film critics each use their own rating system to decide whether a movie is worth watching. Many online platforms aggregate critic data in different ways in an attempt to give a general concensus on whether a movie is worth watching or not. I have obtained film critic data from Rotten Tomatoes as it hosts a large amount of movies, each with many reviews. I cleaned the data with Excel VBA. I used Python to normalize reviews to a 5 point scale, and get the mode for each movie, while also displaying further statistics.
