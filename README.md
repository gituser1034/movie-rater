#  Rotten Tomatoes Movie Rating Data Analysis
Data was manually obtained (copy and pasted) from Rotten Tomatoes, cleaned with Excel VBA, and processed in Python.   

Rotten Tomatoes determines critic ratings by grabbing data from all across the internet. These critics all use a different scale rating system. Some don't give a rating,
some use a scale of 4, 5, 10, or 100, and some give letter ratings. From this critics rating it places a movie into one of 2 categories, good or bad. For example, if a movie is 3/5, it will be rated as good. Then, a movie is given a score based on the amount of good and bad reviews it has. If there are 100 reviews, and 90 people gave 3/5, the movie would be given a 90% on Rotten Tomatoes. Obviously there is a big problem here, the potential for artificially inflated movie reviews. I decided to investigate this problem.
